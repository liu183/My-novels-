# 《重生八〇，断亲后我领全镇致富》

男频短剧实战项目：基于2026番茄改编风向标创作的爽文爽剧。

## 项目信息

- **标题：** 《重生八〇，断亲后我领全镇致富》
- **类型：** 男频短剧 × 快节奏打脸 × 年代重生 × 家庭爽文
- **风格：** 爽快、打脸、复仇、血性、小镇氛围
- **结局：** 开放式（黑凤凰悬念）
