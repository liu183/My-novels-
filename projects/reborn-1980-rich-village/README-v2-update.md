# 《重生八〇，断亲后我领全镇致富》

男频短剧实战项目：基于2026番茄改编风向标创作的爽文爽剧。

## 项目信息

- **标题：** 《重生八〇，断亲后我领全镇致富》
- **类型：** 男频短剧 × 快节奏打脸 × 年代重生 × 家庭爽文
- **风格：** 爽快、打脸、复仇、血性、小镇氛围
- **结局：** 开放式（黑凤凰悬念）
- **当前版本：** V2（三轮重写完成）

## 使用指南

### 如何使用这个项目进行创作？

1. **从 Step 2 开始：** 阅读锚点提要，了解故事核心
2. **参考结构：** Step 5的15节拍结构是主骨架
3. **查看场景：** Step 6的27场景大纲是细化方案（V2）
4. **确认对白：** Step 8的3个关键场面对白可作为模板
5. **检查节奏：** Step 10的节奏曲线控制爽感密度
6. **验证尾声：** Step 11的结局方案和续作伏笔

### 进入实际创作前检查

- [ ] 锚点提要（Step 2）与结构（Step 5）一致
- [ ] 场景大纲（Step 6）符合节奏设计（Step 10）
- [ ] 关键对白（Step 8）符合角色设定（Step 3）
- [ ] 母题暗线（Step 9）有明确指向
- [ ] 结局方案（Step 11）符合主题（Step 4）
