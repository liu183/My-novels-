# Step 4: 主题确立

## 主题命题

只有断绝原生家庭的吸血，靠自己的双手和智慧，才能翻身致富并真正活出尊严。

## 反题/对位

血浓于水，为了复仇而割裂亲情，会失去更重要的东西——家族归属感；而且过于个人化的成功，会引来更大的仇恨和威胁。

## 论证路径（3步）

### 1. 提出阶段（Act I）
林建国回到1980，在父母偏心压榨的瞬间，掀桌子分家断亲。他用信息差独自致富，盖起新瓦房，用行动证明"不需要原生家庭，我也能活好"。主题被初步呈现：个人奋斗 + 断亲 = 成功。

### 2. 反驳阶段（Act II）
赵恶霸砸毁林建国的鱼塘，打伤他，背后有王副县长撑腰；村里人都劝林建国认命，"你斗不过的"。林建国陷入困境，开始反思：难道我只是另一个孤身复仇者？我会不会也引来更大仇家？反题质疑：断亲后，你真的快乐吗？新的仇家"黑凤凰"已盯上你。

### 3. 升华阶段（Act III）
林建国召集村民，男女老少全副武装，一起反击赵恶霸。他们不仅是打倒坏人，更是建立新的"家庭"——全村这个大家庭。林建国在村口拒绝父母跪求时，说："血缘不能当饭吃，全村人，才是一家人。"主题被升华：断亲不是割裂所有人，而是建立新的、更有力的"家族"。

## 主题场景锚点（3个关键场景）

### 场景1 - 断亲时刻（S5）
林建国掀翻厨房桌子，摔碎饭碗，指着父母喊"分家"，那一刻，"断亲"不仅是情感决裂，更是对吸血家庭的制度性推翻。

### 场景2 - 黑暗时刻（S17）
赵恶霸砸毁林建国的鱼塘，村民老李劝他"认命吧"，林建国站在泥泞中，血从额头流下，眼神从恐惧转为锋利，主题的反驳达到顶点。

### 场景3 - 反击时刻（S23）
林建国站在村口，身后是男女老少手持农具的村民，和赵恶霸对峙："你强占我的鱼塘，我带你见识什么叫'全村打脸'"，主题的升华实现——断亲后的新家族团结。

## 母题/象征清单（5个）

### 1. 厨房桌子
**象征：** 原生家庭的束缚与压榨

- **首次出现（S3）：** 林福贵在厨房宣布要压榨林建国，桌子是分配不公的场所
- **再次出现（S5）：** 林建国掀翻桌子，摔碎饭碗，象征彻底拒绝被吸血
- **最后一次（S25）：** 林建国站在自家新房门口，父母跪着求情，他身后新房桌子上摆着和全村一起致富的账目

**语义演变：** 压榨工具 → 被推翻的象征 → 新家族的共同账本

### 2. 鱼塘
**象征：** 个人成就的脆弱与集体力量的坚实

- **首次出现（S7）：** 林建国承包鱼塘，代表他个人的小成功
- **再次出现（S10）：** 赵恶霸砸毁鱼塘，个人财富被摧毁
- **最后一次（S23）：** 村民集体保护鱼塘，林建国说"不是我的鱼塘，是全村的"

**语义演变：** 个人成就的象征 → 脆弱性的暴露 → 集体力量的阵地

### 3. 一碗白米饭
**象征：** 尊严和生存的物质基础

- **首次出现（S1）：** 林建国死后，父母给他碗里放了一勺白米饭，屈辱感极强
- **再次出现（S6）：** 陈桂兰被救后吃的第一顿饭，是林建国给她盛的白米饭
- **最后一次（S25）：** 林建国把米泼向门前跪着的父母

**语义演变：** 屈辱的施舍 → 温暖的关怀 → 对吸血行为的终极否定

### 4. 一封信
**象征：** 威胁和未了结的仇恨

- **首次出现（S28）：** "你杀了我爹，我一定要你儿子偿命"
- **再次出现：** 林建国把信藏在抽屉里
- **最后一次（S29）：** 信不见了，桌上有黑凤凰的羽毛

**语义演变：** 威胁信号 → 暂时压制 → 即将到来的更大危机

### 5. 锄头和农具
**象征：** 农民的抗争武器

- **首次出现（S15）：** 村民准备反击时拿出锄头、镰刀
- **再次出现（S20）：** 村民用这些"武器"打垮赵恶霸
- **最后一次（S26）：** 林建国把一把锄头挂在墙上

**语义演变：** 仅仅是农具 → 抗争的武器 → 胜利的纪念品
