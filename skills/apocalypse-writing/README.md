# 末世文写作 - 技能使用说明

## 概述

末世文是番茄科幻品类的主流类型，写作门槛低、易上手。本技能提供从书名创作到金手指设计的完整指导。

---

## 快速开始

### 适用场景
- 新手作者入门创作末世文
- 进阶作者创新末世题材
- 末世向短篇小说/长篇小说

### 推荐学习顺序
1. 阅读 SKILL.md 核心内容
2. 使用以下实战工具
3. 对照检查清单验证
4. 参考爆款作品学习

### 工具 3: 金手指创意库

#### A. 系统类金手指模板

**系统类金手指 = 系统名称 + 3-5个功能 + 升级路径 + 消耗限制**

**模板示例：**

```
【系统名称】：末世农场系统
【初始功能】：
  1. 种植空间（10平）
  2. 作物加速（10倍）
  3. 收获强化（营养翻倍）
【成长路径】：
  - 升级方式：吸收幸存者的感激值
  - Lv2：种植空间20平 + 新作物
  - Lv3：解锁养殖功能
【消耗限制】：
  - 消耗点数或积分
  - 冷却时间24小时
【爽点设计】：
  - 末世中的美食（饿肚子爽点）
  - 不断解锁新作物新鲜感
```

**系统创意列表：**
```
1. 末世农场系统 - 种种田解决末世粮食
2. 末世商城系统 - 商城兑换、买装备
3. 末世旅游系统 - 旅游收集物资
4. 末世宠物系统 - 宠物帮助战斗
5. 末世召唤系统 - 召唤队友/队友重生
6. 末世建筑系统 - 建避难所
7. 末世直播系统 - 直播打赏换物资
8. 末世合成系统 - 物品合成升级
9. 末世职业系统 - 多职业切换
10. 末世任务系统 - 任务奖励强化
```

---

#### B. 物品类金手指模板

**物品类金手指 = 物品名称 + 核心功能 + 使用规则 + 成长路径**

**模板示例：**

```
【物品名称】：空间戒指
【核心功能】：可储存无限物品、可活物进入
【使用规则】：1秒钟存取，意念操控
【成长路径】：可升级（增加空间、增加功能）
【限制条件】：每日限制次 数、冷却时 间
【爽点设计】：末世囤货、安全感、移动仓库
```

**物品创意列表：**
```
1. 空间戒指 - 随身仓库、无限储存
2. 无限复制机 - 物品无限复制（消耗能量）
3. 绝对防御盾 - 绝对防御力、冷却时间长
4. 瞬移手套 - 瞬间移动、范围受限
5. 变身药剂 - 改变形态、时长限制
6. 回溯沙漏 - 时 间回溯、可回溯10次
7. 丧尸控制笛 - 控制丧尸、数量有限
8. 绝对运气箱 - 必定获得好东西、次数有限
9. 万能钥匙 - 开启任何锁/门/宝箱
10. 知识芯片 - 一秒学会任何技能
```

---

#### C. 规则类金手指模板

**规则类金手指 = 规则名称 + 规则描述 + 规则限制 + 规则进化**

**模板示例：**

```
【规则名称】：前缀赋权
【规则描述】：可给任何物品添加前缀名、赋予属性
【规则限制】：每天最多3个、消耗精神力100点
【规则进化】：解除次数限制、添加更多功能
【爽点设计】：创意强、组合多变、可玩性高
```

**规则创意列表：**
```
1. 前缀赋权 - 物品前缀赋予属性
2. 属性编辑 - 编辑物品属性（比如让水变毒）
3. 物品合成 - 两个物品混合出新物品
4. 概率操控 - 操控某个事件概率
5. 命运倒退 - 把某个人倒退回初始状态
6. 规则利用 - 利丧尸/人类规则对抗
7. 任务强制 - 强制触发某人的任务
8. 剧本编辑 - 编辑下一段剧情走向
9. 存档读取 - 可以存档读取（死亡重来）
10. 无限复活 - 死后可以在指定地点复活
```

**召唤创意列表：**

1. 历史人物召唤 - 召唤历史英雄

6. 丧尸召唤 - 召唤非攻击性丧尸（蛙崽）
7. 建筑召唤 - 召唤避难所/武器
8. 武器召唤 - 召唤武器/装备

#### E. 异能类金手指模板

**异能类金手指 = 异能名称 + 异能效果 + 成长路径 + 限制条件**

**模板示例：**

```
【异能名称】：无限拾取
【异能效果】：可拾取任何物品、甚至别人异能
【成长路径】：不断强化拾取范围和速度
【限制条件】：冷却时间、拾取后物品绑定到主角
【爽点设计】：无限成长、爽感足
```

**异能创意列表：**
```
1. 无限拾取 - 拾取任何物品、甚至异能
2. 属性转化 - 丧尸属性转化到主角
3. 吸收进化 - 吸收生物特征
4. 融合觉醒 - 融合多种异能
5. 绝对防御 - 绝对或相对无敌
6. 意识操控 - 控制丧尸/人类
7. 空间裂隙 - 瞬间传送到随机地点
8. 时间操控 - 时间暂停/加速/减慢或回溯
9. 未来视线 - 看到未来片段
10. 命运织造 - 改变他人命运走向
```

### 工具 4: 开篇结构模板

**末世文开篇（0-3万字）标准结构：**

#### 第一章：重生确认 + 抛出金手指

```
【开头300字】
- 描述主角状态（重生前一秒死亡）
- 闪回前世末世惨状（停水停电、丧尸围城）
- 主角死亡、重生

【确认重生】
- 醒来后确认时间在末世之前
- 产生复仇、布局的想法

【抛出金手指】
- 金手指激活/发现
- 使用一次，展示效果（爽点）
- 确认金手指的强大

【核心冲突】
- 末世倒计时（距离末世还有XX天/XX小时）
- 主角急需解决的问题（资金、物资、复仇）

【留下悬念】
- 末世即将来临怎么办？
```

#### 第二章：金手指试用 + 获取资源

```
【金手指试用】
- 详细展示金手指使用效果
- 获得的物资/能力

【获取资源】
- 怎样获取资金/物资？
- 前世仇人有哪些资产可以夺取

【第一个小行动】
- 采取行动（获取第一笔资金/物资）
- 展示主角杀伐果断

【收服第一个队友铺垫】
- 见到未来队友的线索
- 为后续收服埋伏笔

【铺垫更大的冲突】
- 暗示末世来临的征兆
- 为第3章升级做铺垫
```

#### 第三章：囤货布局 + 建势力雏形

```
【大行动】
- 大量囤货/布局
- 展示主角计划周密

【金手指进阶】
- 解锁新功能
- 发现更强用法

【收服第一个队友】
- 正式收服
- 展示队友价值/实力

【末世倒计时】
- 时间迫近，开始准备
- 为开篇结尾制造紧张感

【最后悬念】
- 末世刚刚开始的前一刻
- 或者已经进入末世初段
- 结尾：末世来临，真正的好戏开始
```

## 实例演示

### 例子 1：新手配置

```
书名：《末世：我开局复制了全世界》

世界设定：
  类型：丧尸末世 + 异能觉醒
  特点：传统设定 + 复制异能（创新）

人设：
  角色：重生 + 枭雄
  金手指：复制异能（可以复制任何物品）

金手指：
  名称：无限复制
  功能：
    1. 复制任何物品（消耗能量）
    2. 复制后质量100%
    3. 可以复制异能核心
  成长路径：
    - Lv1：复制小物品（水、面包）
    - Lv2：复制武器、装备
    - Lv3：复制异能核心
  限制：
    - 每日只能3个物品
    - 能量通过击杀丧尸获得

主线：
  前期（0-5万字）：复制囤货 + 建避难所 + 复仇
  中段（5-20万字）：复制武器、装备，建立势力
  后段（20万字以上）：复制顶级装备，统一幸存者基地
```

---

### 例子 2：创新配置

```
书名：《末世游戏：我能给万物加前缀》

世界设定：
  类型：冰河末世（创新）
  特点：全球冰封 + 极寒天气 + 创新金手指

人设：
  角色：重生 + 枭雄但有温度
  金手指：前缀赋权（规则类绝对创新）

金手指：
  名称：前缀赋权
  功能：
    1. 可给任何物品添加前缀名
    2. 前缀赋予特殊属性
    3. 可以给丧尸添加前缀
  成长路径：
    - Lv1：添加简单前缀（白、黄、蓝）
    - Lv2：添加中等前缀（紫、金）
    - Lv3：添加特殊前缀（禁咒、无敌）
  限制：
    - 每日限制3个前缀
    - 消耗精神力

金手指创新点：
  可玩性强、创意无限、组合多变

主线：
  前期：通过前缀赋权保证生存（给保暖物品加前缀）
  中段：探索创新前缀组合，建立势力
  后段：终极前缀（禁咒/无敌），终结末世
```

## 学习建议

### 1. 多读末世文
- 每周读2-3篇同类型作品
- 收集好的开头、金手指、情节
- 制作末世文灵感库

### 2. 模仿开篇
- 选择一篇爆款作品
- 分析前三章结构
- 用自己的方式写一个类似开篇

### 3. 脑洞练习
- 每天想1个末世金手指
- 写在笔记本上
