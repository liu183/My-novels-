# Auto Novel Creator - 基于AI的全自动小说创作引擎

## 概述

这是一个全自动化的12步小说创作系统。基于用户的灵感或参考素材，系统将自动执行从创意生成到最终小说编写的完整流程，仅在关键节点要求用户确认。

**核心特点：**
- 🚀 全流程自动化 - 从一个想法到完整小说
- 🤖 智能决策引擎 - 基于故事学原理自动生成
- 📍 关键节点确认 - 只在必要时打断用户
- 📊 结构化输出 - 每步都有明确格式和验证标准
- ♻️ 可迭代优化 - 支持重写和修正

## 工作流程

### Phase 1: 初始化 (自动)

1. 收集用户输入
   - 灵感/创意/参考素材
   - 类型偏好（可选）
   - 风格偏好（可选）
   - 禁忌元素（可选）

2. 分析输入
   - 提取核心概念
   - 识别类型特征
   - 评估可行性

### Phase 2: 12步自动化创作 (半自动)

| Step | 阶段 | 用户确认 | 自动化内容 |
|------|------|----------|------------|
| 1 | 创意生成 | ✅ 选择概念 | 生成3-6个200字故事概念 |
| 2 | 一页提要 | ✅ 锚点锁定 | 扩展为≤1000字详细提要 |
| 3 | 角色设计 | ❌ 自动 | 生成8-12个角色卡 + 关系网 |
| 4 | 主题确立 | ❌ 自动 | 主题命题 + 反论证 + 母题 |
| 5 | 结构节拍 | ❌ 自动 | 15节拍完整结构 + 伏笔分布 |
| 6 | 场景大纲 | ❌ 自动 | 30-60场景详细规划 |
| 7 | 关键场面 | ❌ 自动 | 8-12个关键场面设计 |
| 8 | 对白创作 | ❌ 自动 | 5-8个核心场面完整对白 |
| 9 | 象征暗线 | ❌ 自动 | 5-7个母题 + 副线布置 |
| 10 | 节奏控制 | ❌ 自动 | 张力曲线 + 转场策略 |
| 11 | 结局设计 | ✅ 选择方案 | 2-3个结局方案 + 续作伏笔 |
| 12 | 最终输出 | ❌ 自动 | 完整小说初稿 (3-8万字) |

### Phase 3: 交付与保存 (自动)

1. 项目整理
   - 生成项目文档
   - 创建目录结构
   - 汇总创作数据

2. 代码仓提交
   - 自动 commit 各步骤
   - 推送到指定分支
   - 生成创作日志

## 自动化引擎设计

### 决策点：Step 1 - 创意生成

**输入处理：**
- 提取关键词（类型、风格、核心概念）
- 分析市场趋势（参考成功作品）
- 生成冲突配置（内在冲突 vs 外在冲突）

**自动生成参数：**
```
concept_count = 3  # 默认生成3个可选
concept_length = 200  # 每个概念200字
genre_weight = 主类型60% + 混搭40%
twist_density = 中等偏高（确保每个概念有反转潜力）
```

**用户确认点：**
- 展示所有概念（标题、logline、核心描述）
- 用户选择一个概念或要求修改

---

### 决策点：Step 2 - 锚点提要

**自动生成策略：**
- 基于选定概念，扩展600-1000字详细提要
- 遵循6段式结构（开端、激励、中段、低谷、抉择、余韵）
- 生成角色阵列（3-5个主要角色功能）
- 明确主题与反题

**验证标准：**
- [ ] 因果链完整，无巧合
- [ ] 每阶段都有冲突升级
- [ ] 开放问题为后续步骤留空间
- [ ] 字数在600-1000之间

**用户确认点：**
- 展示完整提要
- 用户确认锁定（成为锚点）或要求修改

---

### 自动化：Steps 3-10

这些步骤完全自动化，基于锚点提要自动生成：

**Step 3 角色设计**
- 自动生成8-12个角色卡（每个≤180字）
- 构建关系网络图
- 每个角色包含：名字、功能、动机、软肋、弧光

**Step 4 主题确立**
- 基于2的故事冲突自动推导主旨
- 生成反题（相反观点）
- 设计5个母题（递进式重复3次）

**Step 5 结构节拍**
- 使用15节拍模板
- 自动配置节拍到具体场景
- 预布反转和伏笔

**Step 6 场景大纲**
- 根据目标字数计算场景数（短篇30场，中篇60场，长篇150场）
- 每个场景包含：目标、冲突、转折、信息收获
- 自动分配到15节拍下

**Step 7 关键场面**
- 识别关键场景（比例约15%）
- 设计8-12个关键场面卡片
- 每个场面包含：地点、人物、动作爆点、视觉冲击

**Step 8 对白创作**
- 选择5-8个场面进行完整对白编写
- 包含潜台词和动作提示
- 每个对白约250-350字

**Step 9 象征暗线**
- 基于5个母题设计副线
- 规划信息释放时序
- 将伏笔分布到场景中

**Step 10 节奏控制**
- 分析场景密度，生成节奏曲线
- 识别张力峰值（每幕2-3个高潮点）
- 设计转场策略

---

### 决策点：Step 11 - 结局设计

**自动生成策略：**
- 基于主题和角色弧光，提供2-3个结局方案
- 每个方案包含：权力终局、角色命运、世界余波、续作伏笔

**常见结局类型：**
- A型：开放悬念（为续作留钩子）
- B型：圆满收尾（角色成长完成）
- C型：悲剧收尾（主题强化）
- D型：反转收尾（意料之外）

**用户确认点：**
- 展示所有结局方案
- 用户选择一个或将方案融合

---

### 自动化：Step 12 - 最终输出

基于前面所有步骤，自动生成完整小说：

**生成策略：**
- 遍历Step 6的所有场景
- 使用Step 5的节拍作为骨架
- 填充Step 7的场面设计
- 嵌入Step 8的对白
- 贯穿Step 9的母题和暗线
- 控制Step 10的节奏和张力

**质量控制：**
- 每场景200-600字（根据重要性）
- 对白场景占比30-40%
- 描写占比20-30%
- 心理占比20-30%

**输出格式：**
```
小说项目/
├── README.md           # 项目总览
├── novel.md            # 完整小说文本
├── steps/              # 12步骤文档（自动生成）
└── metadata.json       # 创作数据和统计
```

## 实现架构

### 技术实现

这个技能通过以下方式实现：

1. **子任务编排**
   - 使用 `sessions_spawn` 创建12个子任务
   - 每个子任务专注一个步骤
   - 主任务负责协调和用户确认

2. **提示工程**
   - 每个步骤有专门的系统提示词
   - 基于先前步骤的输出作为上下文
   - 使用结构化输出格式（JSON/Markdown）

3. **状态管理**
   - 维护一个项目状态对象
   - 每步完成后更新状态
   - 支持断点续传

4. **质量控制**
   - 每步都有验证清单
   - 失败时自动重试或提示用户
   - 支持局部重新生成

### 主任务流程

```
1. 读取用户输入
2. spawn Step 1 子任务 → 生成概念
3. 用户确认概念
4. spawn Step 2 子任务 → 生成锚点
5. 用户确认锚点
6. for i in [3..10]:
7.     spawn Step i 子任务
8.     等待完成并验证
9. spawn Step 11 子任务 → 生成结局
10. 用户确认结局
11. spawn Step 12 子任务 → 生成小说
12. 整理项目并提交到代码仓
13. 输出完成报告
```

## 技术实现参考

### 主任务代码结构

```python
class AutoNovelCreator:
    def __init__(self, user_input):
        self.input = user_input
        self.state = {}
        self.project_dir = f"novel-{timestamp}"

    def run(self):
        # Step 1: 概念生成
        self.step1_ideation()
        user_confirm = self.get_user_confirmation()
        if not user_confirm:
            self.step1_retry()

        # Step 2: 锚点提要
        self.step2_synopsis()
        user_confirm = self.get_user_confirmation()
        if not user_confirm:
            self.step2_retry()

        # Steps 3-10: 全自动
        for i in range(3, 11):
            self.exec_step(i)
            self.validate_step(i)
            self.commit_step(i)

        # Step 11: 结局选择
        self.step11_endings()
        user_confirm = self.get_user_confirmation()

        # Step 12: 最终小说
        self.step12_generate_novel()

        # 整理和提交
        self.finalize_project()
        self.push_to_github()
```
