# Male Web Novel Creation Guide
# 男频网文创作指南

This skill provides a structured framework for creating engaging male-dominated web novels on Chinese platforms like Fanqie Novel (番茄小说).

## Core Creation Framework

### Phase 1: One-Sentence Story Concept
Before writing, crystallize your story into one sentence:

**Formula**: `xx (negative-value adjective) 的 xx (protagonist's identity) 想要 xx (desire, positive value) 而去 xx 的故事`

**Examples**:
- 废柴的天才想要出人头地而去成为斗帝的故事
- 被遗弃的医女想要生存必须去陪葬的故事
- 退休的战神想要报恩而去都市中掀起血雨腥风的故事

**Key Points**:
- Positive value must oppose negative value
- Desire should be concrete/tangible
- Test by asking others: "Would you want to read a story about xx?"

### Phase 2: Build Story Pivots (故事支点)
Strong web novels need multiple elements that can spawn stories. Any pivot can serve as the title.

**Character Pivots**: Role contradictions
- Identity + expected positive value vs. negative reality
- Example: 宗门师父 (teacher) → 期望: "传道授业解惑" vs. 现实: 玩世不恭、离经叛道
- Rationale for the negative value becomes story material

**World/Environment Pivots**: Rule conflicts
- Create a world with **one new rule** that conflicts with protagonist/reader values
- Reader asks "Why?" → backstory spawns stories
- Example: 学校床帘禁令 → because someone raised a 300lb pig in dorm
- Rule vs. values collision generates ongoing story material

**Cheat Ability Pivots** (金手指):
- Systems, special abilities, luck powers
- Critical: Protagonist must **drive** the ability, not vice versa
- Creative twist: Make the ability oppose protagonist's desire (e.g., runaway prince gets "Emperor System", reborn money-loser gets "Lose Money System")

**Suspense Pivots**:
- Hook readers with mysteries
- Setup questions → How did they get here? What happens next? Can they survive?
- Critical: Must resolve logically. Suspense that doesn't pay off is not a story

**Provocative Actions** (二次行为/过激行为):
- Protagonist takes overly extreme measures
- Triggers cascading events
- Example: Wants to learn technique → asks teacher (first action) → breaks into teacher's room at night with junior sister (second action) → consequences ensue

**Inciting Incidents** (激励事件/干扰事件):
- Event that disrupts status quo, forcing protagonist to make choices
- Can be threat, reward, punishment, or opportunity
- Example: Sudden 10 billion inheritance → how does this change protagonist's fate?

**Multiple pivots**: Combine several for richer content

### Phase 3: Opening Hooks (切入事件)
Open with inciting incidents or provocative actions to set expectations immediately.

**Essential opening elements** (adapted from Story Strategy):
1. Show protagonist's situation and dissatisfaction with status quo
2. Give readers reasons to like protagonist
3. Subject protagonist to unfair harm/hardship
4. Show protagonist facing or entering danger
5. Cheat ability appears, creating opportunity
6. Establish protagonist's short-term goal
7. End with compelling plot hook

**Guidelines**:
- Don't include all elements rigidly in fixed order
- Learn from successful works by analyzing how they use these techniques
- All elements should appear as early as possible in male-dominated fiction
- Avoid mechanical copying — adapt naturally

### Phase 4: Outline Structure (三幕式/节拍器)
Story satisfaction = fulfilling expectations (爽点). Beyond face-slapping power fantasies, this includes:
- Hard-won love achieved
- Survival after long escape
- Problem-solving breakthroughs
- Light found in darkness

**Three-Act Structure**:
1. **Setup** (建制): Introduction, status quo
2. **Confrontation** (对抗): Can split into Progression and Turning Point
3. **Resolution** (结束): Climax and aftermath

Simplified: 起 (beginning), 承 (develop), 转 (turn), 合 (conclude)

**Emotional Curves**:
- Rising curve: Reader satisfaction (beating enemies, gaining treasures, achieving goals)
- Falling curve: Author sets expectations (conflicts, surprises, threats to protagonist)

- **Setting expectations**: Anything that goes against reader predictions
- **Fulfilling expectations**: Events that satisfy reader's emotional desires

**Multi-level structure**:
- Apply three-act to entire novel (main storyline)
- Apply to individual volumes/arcs (secondary structure)
- Apply to scenes/sequences (emotional tension and release)
- Even conversations and fights can use this framework

**Avoid repetition**:
- Don't use the same satisfaction pattern (like constant face-slapping)
- Viate expectation-setting and fulfillment for freshness
- Use multiple overlapping emotional curves
- Create custom beat sheets (like Snyder's Save the Cat)

**Practical approach**:
- Start with Volume 1 (150k-200k words; minimum 100k)
- Place major climax past 100k mark (critical for platform metrics)
- Build main outline first, then fill details
- Outlines can anytime if you find better plot points

## Title and Opening Strategy

### Title Creation
**Purpose** in web novels beyond identification:
- Set reader expectations
- Filter/target specific readers

**Good title principles**:
- Lively, engaging phrasing (not stiff/formulaic)
- Grounded language with contrast/reversal
- Summarize core concept or highlight scenes
- Clear, accurate wording (no made-up words)
- Under 15 characters including punctuation

**Title creation process**:
1. Identify core, novel, interesting setting or joke (expand to resonant scenes if none)
2. Summarize in 1-2 sentences
3. Replace outdated/vague words: "肿么破" → "人麻了", "佛系" → "开摆" (lying flat), generic "美女" → "高冷校花", "病娇女帝"
4. Structure with popular, clear phrasing
5. Condense to under 15 characters

### Opening Best Practices
- Enter plot quickly; minimize long world-building backstories at start
- Clear main thread direction from beginning
- Use urgent, conflict-heavy events to grab attention
- Plant suspense or reverses; don't spoil ending upfront

## Inspiration Sources
- Current events and news (时事热点)
- Short video platform trends and memes (短视频热梗)
- Hit variety shows (热门综艺)
- Re-examine literature with fresh perspective

## Platform Notes (Fanqie Novel/番茄小说)
- **Read-through** (完读率): Critical metric past 100k words
- **Encouraged**: Positive-value themes, creative innovation
- **Not encouraged**: Manipulation/harem/lazy-power plots
- **Avoid in arts/entertainment genres**: Copyright risks; no political figures/celebrity parodies

## Quick Reference

**Success factors**:
- Strong story concept with clear value conflicts
- Multiple engaging story pivots
- Compelling opening with immediate hooks
- Emotional curve mastery (tension/release cycles)
- Genre-specific conventions and expectations

**Red flags**:
- Slow starts (excessive backstory/lore dumps)
- Single satisfaction pattern (monotonous pacing)
- Broken suspense (unresolved mysteries)
- Cheat abilities that drive protagonist (not vice versa)
- Generic titles without clear hook
