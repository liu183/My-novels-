# IP Adaptation Guide - 技能使用说明

## 概述

本技能提供 IP 改编专项指导，帮助作者创作更容易被影视、动漫、游戏等改编的小说。

## 快速开始

### 适用场景

- 创作短剧向小说
- 写作网剧/电视剧改编向作品
- 打造动漫/游戏 IP 潜力作品

### 基础流程

1. 阅读 `SKILL.md` 核心内容
2. 使用以下模板进行创作
3. 对照检查清单验证

## 实用工具与模板

### 模板 1: 角色记忆点生成器

**步骤：**

1. 选择1-2个鲜明标签
   ```
   标签库：
   - 性格：清冷、疯批、腹黑、傲娇、忠犬、奶狗...
   - 身份：赘婿、霸总、神医、神探、刺客...
   - 特征：失忆、重生、穿越、系统...
   ```

2. 设计标志性行为
   ```
   示例：
   - 生气时：捏碎茶杯、眯眼、冷笑
   - 思考时：转笔、咬唇、来回踱步
   - 感动时：眼眶微红、偏头掩饰
   ```

3. 写一句口头禅
   ```
   示例：
   - "有趣"
   - "无趣"
   - "看来你不了解我"
   - "我允许你后悔"
   ```

**示例结果：**

| 标签 | 行为 | 口头禅 | 记忆点描述 |
|------|------|--------|----------|
| 清冷禁欲 | 推眼镜时眯眼 | "无趣" | 一个清冷禁欲的学者，推眼镜时总爱眯着眼睛，说着"无趣" |
| 疯批美人 | 咬唇时眼底闪过戾气 | "嘻嘻" | 甜美如天使，咬唇时眼底却闪过让人胆寒的戾气，一声"嘻嘻"让人毛骨悚然 |

---

### 模板 2: 开篇黄金三章结构

**第一章：立人设 + 抛冲突**

```
【场景】：快速展示主角状态（≤200字）
【标签】：用行动展现1个鲜明标签
【困境】：抛出核心矛盾（复仇/被欺压/意外）
【目标】：主角的第一个行动目标
【结尾】：留下悬念
```

**第二章：展开 + 第一个爽点**

```
【升级】：冲突升级或引入新角色
【配角】：1-2个关键配角，立人设
【行动】：主角采取行动
【爽点】：第一个小高潮（打脸/展示实力）
【铺垫】：铺垫更大的挑战
```

**第三章：深入 + 悬念钩子**

```
【冲突】：深入矛盾，揭示部分真相
【转折】：新意外或新敌人出现
【悬念】：留下强烈的"然后呢？"
【预告】：暗示更大的战斗/危机
```

---

### 模板 3: 爽点节奏规划表

| 章节/节点 | 爽点类型 | 爽点描述 | 情绪值 (1-10) |
|-----------|----------|----------|---------------|
| 第1章 | 立人设爽点 | 主角用独特方式展现气质 | 6 |
| 第2章 | 打脸爽点 | 小反派被主角教训 | 7 |
| ... | ... | ... | ... |

**爽点类型：**
- `打脸`: 证明主角实力/智慧
- `逆袭`: 从困境中翻身
- `解谜`: 揭开线索真相
- `情感触动`: 暖心/感动时刻

---

### 模板 4: IP改编检查清单

**人设检查 [ ]**
- 主角有1-2个鲜明标签
- 主角目标明确
- 配角有记忆点
- 有可传播的"梗"

**情节检查 [ ]**
- 前3章确立主角、冲突、目标
- 爽点密集（每章≥1个小爽点）
- 主线驱动力强
- 中段冲突不断升级

**节奏检查 [ ]**
- 前3章快速入局
- 每章结尾有悬念
- 信息分批释出
- 无"说明书式"设定

**改编潜力 [ ]**
- 动作 > 内心戏
- 人物关系清晰
- 有视觉化名场面
- 世界观完整（如有）

通过率 ≥75% 具备良好改编潜力？

## 不同改编形态创作建议

### 短剧向

**特点：**
- 节奏极快
- 爽点密集
- 人物关系简单
- 爆发力强

**创作要点：**
```
✅ 开篇3章：立人设 + 抛冲突 + 第一个爽点
✅ 每3-5节（约10分钟）一个小高潮
✅ 每10节（约30分钟）一个大反转
✅ 人物关系：主角 + 1-2个对手 + 1-2个盟友
❌ 避免复杂副线
❌ 避免长篇心理描写
❌ 避免缓慢的日常篇章
```

---

### 网剧/电视剧向

**特点：**
- 结构完整
- 角色饱满
- 多条副线
- 视觉化场景

**创作要点：**
```
✅ 主线 + 2-3条副线（情感线、阴谋线、成长线）
✅ 角色弧光完整（主角 + 重要配角）
✅ 视觉化场景丰富
✅ 集体高潮（团队协作打Boss）
✅ 季节性结构（每季一个大故事）
❌ 避免过于复杂的设定
❌ 避免无法实现的特效
```

---

### 动漫/番剧向

**特点：**
- 世界观重要
- 角色造型强
- 画面感丰富
- 技能系统清晰

**创作要点：**
```
✅ 世界观完整（种族、国家、能力体系）
✅ 角色造型设计（发色、服装、标志性装备）
✅ 战斗/能力系统（等级、招式、升级）
✅ 画面感强的场景（大场面、华丽特效）
✅ 宿敌设定（竞争对手/宿命对手）
✅ 团队模式（主角团/公会/战队）
```

---

### 有声书/广播剧向

**特点：**
- 对话重要
- 氛围到位
- 情感细腻
- 叙事节奏适口

**创作要点：**
```
✅ 对话丰富自然（占40-50%）
✅ 场景氛围描述（音效参考：风声、脚步、打斗）
✅ 情感心理描写（细腻、有层次）
✅ 角色声音特点（通过说话方式展现）
✅ 适合口述的节奏（不跳跃、不混乱）
```

---

### 游戏改编向

**特点：**
- 世界观宏大
- 角色能力系统
- 爽点可重复
- 规则清晰

**创作要点：**
```
✅ 世界观完整（地图、历史、种族）
✅ 角色能力系统（技能树、装备、属性）
✅ 爽点可重复（等级提升、装备获取、PVP）
✅ 规则清晰（战斗规则、任务系统、副本）
✅ 多职业/种族设定（丰富可玩性）
✅ BOSS设定（大Boss，掉落奖励）
```

## 常见问题 Q&A

**Q: 短剧和网剧有什么区别？**
A: 短剧是竖屏短剧，单集1-3分钟，节奏更快，爽点更密集，人物更精简。网剧类似于传统电视剧，单集20-45分钟，可以有更多剧情铺垫和副线展开。

**Q: 什么样的题材最适合短剧？**
A: 复仇、逆袭、打脸、甜宠、系统、重生等类型最适合短剧，因为这些题材自带强冲突和密集爽点。

**Q: 开篇前三章要写多久？**
A: 短剧通常10-15节，对应小说5000-10000字。网剧需要更长，第一集20-30分钟，对应小说1-2万字。

**Q: 什么是"爽点密度"？**
A: 在单位时间内（每章/每集）提供的小高潮次数。短剧要求最密集，每3-5分钟就要一个爽点。小说通常每章至少1个小爽点。

**Q: 怎么判断一个角色记忆点是否好？**
A: 看是否能让读者用一句话描述清楚，且描述时带有明显的画面感。如果读者能轻易说出"那个xxx的角色"，就说明记忆点成功了。

## 工作流程示例

### 场景：创作一部短剧向重生打脸小说

```
1. 选题阶段
   - 类型：重生+打脸+爽文
   - 核心钩子：主角重生回到过去，痛打前世仇人

2. 造人设（使用记忆点公式）
   - 主角标签：疯批美人 + 隐忍十年
   - 行为：嘴角扯起病态笑容
   - 口头禅："十年了，换我了"

3. 规划开篇（黄金三章）
   - 第1章：重生 → 确认重生时间 → 发誓复仇
   - 第2章：仇家上门 → 智退仇家 → 展示部分实力
   - 第3章：调查线索 → 发现更大阴谋 → 留悬念

4. 设计爽点节奏
   - 第1章：重生爽点 (6/10)
   - 第2章：打脸小反派 (7/10)
   - 第3章：大阴谋浮现 (8/10)
   - 每3章一个小高潮
   - 每10章一个大反转

5. 对照检查清单验证
   - 人设：鲜明标签 ✓
   - 情节：前3章立冲突 ✓
   - 节奏：每章有悬念 ✓
   - 改编：适合短剧 ✓

6. 开始创作（配合 auto-novel-creator）
```

## 提升技巧

### 1. 多看爆款改编作品

- 短剧：番茄小说2025年改编榜650部作品
- 网剧：分析《庆余年》《赘婿》等改编逻辑
- 动漫：研究《鬼灭之刃》《咒术回战》等世界观

### 2. 模仿开篇

找3-5部同类型的爆款作品：
- 拆解前三章结构
- 分析角色记忆点
- 记录爽点节奏
- 模仿学习

### 3. 频繁验证

写完后问自己：
- 主角是谁？（一个标签回答）
- 他/她要做什么？（一句话目标）
- 开篇有什么冲突？（明确困境）
- 前三章有爽点吗？（列出来）
- 结尾想看下一章吗？（诚实回答）
