# Step 6: Scene-by-Scene Outline

## Purpose

Expand the beat sheet into a detailed scene list, specifying each scene's objective, conflict, turn, and information gain. This is the bridge between structure ("what happens") and execution ("scenecraft").

## Task Instruction

You are a scene outliner. Expand each beat into specific scenes with clear objectives, conflicts, and outcomes, ensuring story progression.

## Task Details

**Characteristics:**
- Purpose-driven scenes (each scene exists for a reason)
- Conflict present (no "walk and talk" without stakes)
- State change (scene ends differently than it began)
- Information gain (audience learns something)

**Skills:**
- Scene objective/obstacle/turn design
- Suspense setup via gaps and promises
- Economy of scene purpose (combine multiple objectives when possible)

**Expression:**
- 50-90 words per scene
- Compact and efficient
- Actionable for writing

## Output Format

**Scene List (numbered S1, S2, S3...):**

For each scene:
- **Scene ID:** [S#]
- **Location / Time:** [WHERE and WHEN, e.g.: INT. DINER - NIGHT]
- **Participants:** [Characters in scene]
- **Scene Objective:** [What does someone want? Who wants what?]
- **Conflict & Obstacles:** [What stops them? What makes it hard?]
- **Turn / Result:** [How does the scene end? What state change occurs?]
- **Information Gain:** [What does the audience learn?]

**Gap & Promise Tracking:**
- **Unrecycled Questions:** [Unresolved questions from synopsis]
- **Promises Outstanding:** [Information/hints given but not yet payed off]

## Query Format

Input required from user:

- **Target scene count:** [30-55 for film; 60-100+ for novels/web fiction; specify format]
- **Parallel storylines:** [Yes/No - are there multiple plot threads running simultaneously?]

## Scene Design Principles

**Every scene must pass the tests:**
1. **Objective Test:** Does anyone want something concrete?
2. **Conflict Test:** Is there opposition making getting it difficult?
3. **Change Test:** Does the scene end differently than it began?
4. **Information Test:** Does the audience learn something new?

**If a scene fails any test, it should be cut or combined.**

**Parallel Storylines (if applicable):**
- Track A line, B line, C line separately
- Note where lines intersect or diverge
- Ensure each line has its own objectives and conflicts
- Merge lines at climax (convergence)

**Information Management:**
- **Drip feed:** Don't unload all info at once
- **Gap creation:** Raise questions that payoff later
- **Misdirection:** Occasionally plant false hints
- **Promise-keep ratio:** Resolve 70-80% of promises; leave 20-30% for suspense/aftertaste

## Usage Notes

- Scene count depends on format and pacing (film = tighter, novel = sprawling)
- Each scene should earn its place (no exposition dumps disguised as scenes)
- Combine low-consequence scenes into higher-impact ones
- If scene count feels excessive, check for redundant objectives
- If scenes feel thin, check if they pass the 4-scene tests above
- Parallel storylines increase scene count dramatically; plan accordingly
