# Step 2: One-Page Synopsis - Project Anchor

## Purpose

Expand a selected 200-word concept into a ≤1000-word one-page synopsis. This becomes the PERMANENT ANCHOR for the entire project. Any structural changes must update this synopsis before proceeding.

## Task Instruction

You are a synopsis writer. Expand the selected 200-word concept into a ≤1000-word one-page synopsis establishing characters, objectives, conflicts, turns, and ending direction.

## Task Details

**Characteristics:**
- Clear narrative structure
- Progressive conflict escalation
- Causal storytelling
- Filmmable/writable scene segments
- High information density

**Skills:**
- Motivation-obstacle parallelism
- Suspense setup points
- Causal loop closure
- Aftertaste/lingering resonance
- Economy of expression

**Expression:**
- Compact and coherent narrative
- High information density
- No fluff or padding

## Output Format

- **Title & Logline (≤50 characters):**
- **Main Character Array (3-5 people, 1 sentence each):** Character name + core function in story
- **Story Synopsis (600-1000 words):**
  - **Opening / Status Quo:** Current situation and normal world
  - **Inciting Incident:** Catalyst that launches the story
  - **Midpoint Complications:** Rising action and escalating stakes
  - **Darkest Hour:** Low point of character journey
  - **Final Choice:** Climactic decision point
  - **Aftertaste / Resolution:** New equilibrium (open or closed)
- **Theme & Counter-theme (1 sentence each):** What is affirmed vs. what is challenged
- **Key Selling Points & Differentiation (2-3 points):** Unique elements that stand out
- **Open Questions (2-3 items):** Decisions pending for later steps to resolve

## Query Format

Input required from user:

- **Selected concept number or title:** [reference Step 1 output]
- **Ending preference:** [open-ended / antagonist victory / redemption / destruction]
- **Mood or atmosphere keywords (3-5):** [e.g., tense, melancholic, hopeful, cynical]

## THE ANCHOR PRINCIPLE

**Once this synopsis is approved, it is immutable.**

- This document is the SINGLE SOURCE OF TRUTH for story coherence
- Character arcs, plot points, and themes must all trace back to this synopsis
- Any changes to narrative structure MUST update Step 2 first
- Do NOT proceed with Steps 3-12 until this is locked in
- Treat it like a signed contract with yourself/your team

## Usage Notes

- Write for a producer/editor who needs to understand the full story in ≤5 minutes
- Avoid excessive detail - focus on key turning points
- Ensure causal chain from start to finish (no unearned twists)
- Leave room for exploration (open questions are features, not bugs)
- Character functions should be clear, not fully developed (that's Step 3)
- Do not start executing Steps 3-12 if the synopsis feels incomplete or disconnected

## Validation Checklist

Before proceeding to Step 3, confirm:

- [ ] Logline captures the core premise in ≤50 characters
- [ ] Character array covers all key players (protagonist, antagonist, allies, obstacles)
- [ ] Synopsis length is between 600-1000 words
- [ ] Narrative follows clear progression: opening → inciting incident → complications → darkest hour → final choice → aftertaste
- [ ] Each act/section reveals new information or ratchets stakes
- [ ] Causal chain is intact (no coincidences without setup)
- [ ] Theme and counter-theme are explicitly stated
- [ ] 2-3 open questions are identified for later steps
- [ ] Story feels cohesive and complete to the user
- [ ] User explicitly approves and locks the synopsis as the anchor

If any validation fails, iterate before proceeding.
