# Step 5: Structure - Beat Sheets

## Purpose

Map the synopsis to an executable beat sheet, clarifying each node's function and character state changes. Choose from three structure templates based on story needs.

## Task Instruction

You are a structuralist. Map the synopsis to a beat sheet (3-act, 15-beat, or 8-sequence), specifying each beat's narrative function and character transitions.

## Task Details

**Characteristics:**
- Causally driven (each beat causes the next)
- Tension escalates (stakes rise progressively)
- Turns are clear (reversals are identifiable)
- Pacing feels deliberate

**Skills:**
- Inciting incident design
- Midpoint reversal setup
- Darkest hour construction
- Final choice architecture
- Character state tracking

**Expression:**
- Each beat described in one sentence: "What this beat DOES" (function, not just action)
- Character state changes tracked clearly

## Structure Templates

Choose one based on story needs:

### 3-Act Structure

Classic, flexible foundation. Good for straightforward narratives.

**Act I (Setup):**
- Status Quo / Opening Normal
- Inciting Incident (story launches)
- First Plot Point / No Return (commitment to story)

**Act II (Confrontation):**
- Promise & Plan (how protagonist proceeds)
- Midpoint Reversal (major shift: false victory or false defeat)
- Complications Escalate (stakes rise, obstacles intensify)
- All Is Lost / Darkest Hour (lowest point, rock bottom)

**Act III (Resolution):**
- Final Choice / Climax (confrontation with antagonist/demon)
- New Normal / Aftertaste (resolution, changed world)

### 15-Beat Structure (Save the Cat)

Detailed beat map for genre films. Excellent for high concept, pacing-critical stories.

**Opening Image, Setup, Catalyst, Debate, Break into Two, B Story, Fun & Games, Midpoint, Bad Guys Close In, All Is Lost, Dark Night of the Soul, Break into Three, Finale, Final Image**

(See beat-specific breakdown in extended notes)

### 8-Sequence Structure

Balanced overview. Good for ensemble or complex narratives with multiple storylines.

**Sequence I (Setup), Sequence II (Launch), Sequence III (Rise), Sequence IV (Midpoint), Sequence V (Complications), Sequence VI (Fall), Sequence VII (Climax), Sequence VIII (Resolution)**

## Output Format

- **Structure Template Selected:** [3-act / 15-beat / 8-sequence]

- **Beat Sheet (≤40 words per beat):**
  - **Opening:** [beat list for opening section]
  - **Mid-section:** [beat list for rising action]
  - **Closing:** [beat list for resolution]

- **Character State Changes:**
  - **Protagonist:** [3 transitions: start → midpoint → end]
  - **Antagonist:** [3 transitions: position at start → midpoint → end]
  - **Key Relationship:** [3 transitions: relationship quality at start → midpoint → end]

## Query Format

Input required from user:

- **Preferred structure template:** [3-act / 15-beat / 8-sequence]
- **Twist/reversal frequency:** [low / medium / high - how often should story shift direction]

## Beat Function Examples

**Good beat descriptions (function-focused):**
- "Inciting Incident: Protagonist's mundane life is disrupted when [event], forcing them to confront [stake]"

**Weak beat descriptions (action-focused only):**
- "Inciting Incident: Protagonist wakes up, gets coffee, then sees a car crash"

The difference: Good descriptions explain WHY the beat exists and what it ACCOMPLISHES, not just WHAT happens.

## Character State Tracking

Track emotional/state transitions at key junctions:

- **Start:** Character at opening (beliefs, relationships, circumstances)
- **Midpoint:** Character at midpoint (what's changed? what's been challenged?)
- **End:** Character at resolution (who have they become?)

Example:
```
Protagonist - Start: Isolated cynic (trusts no one)
           → Midpoint: Tentative ally (vulnerable)
           → End: Reconciled realist (wisely open)
```

This ensures arcs are intentional and trackable, not accidental.

## Structure Validation Checklist

Before proceeding to Step 6 (scene outline), confirm:

- [ ] Selected structure template is appropriate for story type
- [ ] Each beat advances the story (no filler beats)
- [ ] Causal chain is intact (beats connect logically)
- [ ] Tension escalates from open to close (story doesn't deflate midway)
- [ ] Character state changes are intentional and visible
- [ ] Midpoint reversal is significant (story shifts direction)
- [ ] Darkest hour feels earned and consequential
- [ ] Total beat count aligns with story length expectations

If validation fails, adjust beat placements before scene planning.
