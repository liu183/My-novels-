# Step 7: Set Pieces & Key Scenes

## Purpose

Generate story event cards and identify 5-7 "key" set pieces that powerfully drive plot and theme. This is where cinematic/visual momentum is designed.

## Task Instruction

You are a set piece designer. Generate story event cards and select 5-7 key scenes to flesh out with complete cinematic execution.

## Task Details

**Characteristics:**
- Highly visualizable (camera-ready/filmable)
- Strong motivation (characters have reasons to be here)
- Clear consequences (scene changes story state significantly)
- High tension (stakes are palpable)
- Memorable moments (scenes audiences recount)

**Skills:**
- Conflict type selection and escalation curves
- Multilayer objective collision (multiple wants in same space)
- Reversal and consequence design
- Visual/action emphasis (props, mechanics, environment interaction)

**Expression:**
- Uniform card format
- Regular events: 50-90 words
- Key set pieces: 100-150 words

## Output Format

**Scene/Event Cards (uniform template):**

For each card:
- **Level:** [EVENT / KEY SCENE]
- **Basics:** [Type / Location / Time / Participants / Objective]
- **Conflict & Risk:** [Explicit (visible stakes) / Implicit (subtextual tension)]
- **Action Path & Branches:** [Option A / Option B (cost / return)]
- **Visual & Action Essentials:** [Props, mechanics, environment interactions]
- **Result & Consequences:** [Changes to character / relationship / world state]
- **Emotional Peak & Theme Echo (Key scenes only):** [Peak moment / motif or symbol activation]
- **Escalation & Pacing Overview:** [Intensity 1-5, peak distribution: mid / end / even]

**Upgrades:** Mark N total scenes, K as KEY set pieces (default N=8, K=5).

## Query Format

Input required from user:

- **Planned output count:** N total events, K key scenes (default N=8, K=5)
- **Type preference:** [confrontation / chase / discovery / betrayal / misunderstanding / temptation]
- **Available location and prop list:** [from previous steps]
- **Escalation intensity preference:** [gradual infiltration / sudden explosion / hybrid]
- **Scene focus:** [confrontation / chase / revelation / sacrifice / betrayal - what drives momentum?]
- **Emotional peak distribution:** [mid / end / evenly spread]

## Key Set Piece Criteria

**Elevate to KEY when:**
- Scene dramatically shifts story direction
- Character's core desire/fear is tested directly
- Theme is explicitly manifested (symbol/motif activated)
- High visual or emotional impact (audience remembers this)
- Consequences are irreversible or transformational

**Key set pieces deserve:**
- More detailed execution (100-150 words vs. 50-90)
- Theme integration note (how scene tests/affirms thesis)
- Emotional peak identification (climax of the scene's arc)
- Symbol/motif activation (what recurring element plays here)

## Conflict Types & Escalation

**Conflict types:**
- **Confrontation:** Direct opposition, test of strength/willpower
- **Chase:** Pursuit/evasion, test of wit/ingenuity
- **Discovery:** Uncovering truths, intellectual revelation
- **Betrayal:** Trust broken, relational rupture
- **Misunderstanding:** False perception driving wrong actions
- **Temptation:** Allure of easy but morally questionable path

**Escalation curves:**
- **Gradual:** Scene builds slowly, tension creeps up
- **Explosive:** Immediate high stakes, all or nothing
- **Hybrid:** Build → explode → aftermath reflection

**Branching:**
Scenes can play out multiple ways; design decision points (A/B paths) with different costs/rewards. This gives narrative flexibility later.

## Usage Notes

- Set pieces are where your story's "movie moment" energy lives
- Not every dramatic event is a key set piece - choose strategically (5-7 per story is typical)
- Key set piece placement affects pacing rhythm (don't cluster all key scenes in one act)
- Visuals should serve story (not just spectacle without function)
- Emotional peaks should feel earned by prior setup
- Escalation planning prevents flat scenes (every scene should move up or down tension, not stay static)
