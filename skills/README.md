# Skills Directory

此目录包含所有写作相关的技能框架。

## Novel Writing Framework

12步互动式AI写作框架，支持从创意生成到最终重写的全流程。

### 内容

**核心文档**：
- `SKILL.md` - 框架总览和快速开始

**参考文档** (12个步骤)：
- `step1-ideation.md` - 创意生成
- `step2-synopsis.md` - 一页提要（⚠️ 锚点步骤）
- `step3-characters.md` - 角色设计
- `step4-theme.md` - 主题开发
- `step5-structure.md` - 结构节拍
- `step6-scenes.md` - 场景大纲
- `step7-setpieces.md` - 关键场面
- `step8-dialogue.md` - 对白与潜台词
- `step9-symbolism.md` - 象征与暗线
- `step10-pacing.md` - 节奏与张力
- `step11-endings.md` - 结局设计
- `step12-rewrite.md` - 重写迭代

### 结构

```

    ├── step2-synopsis.md         # ⚠️ 锚点：提要

    ├── step4-theme.md            # 设计阶段：主题
    ├── step5-structure.md        # 设计阶段：结构
    ├── step6-scenes.md           # 细化阶段：场景
    ├── step7-setpieces.md        # 细化阶段：场面
    └── step8-dialogue.md         # 细化阶段：对白
    ├── step9-symbolism.md        # 精炼阶段：象征
```

### 使用流程

1. 阅读 `SKILL.md` 了解框架整体设计
2. 从 `step1-ideation.md` 开始执行
3. 依次完成所有步骤，重点关注 Step 2（锚点）
4. 根据需要调整参数和输出格式

### 锚点机制

**Step 2 是全文唯一锚点：**
- 一旦确立，不能跨越修改后续步骤
- 任何结构变更必须先更新 Step 2
- 确保叙事连贯性和一致性
